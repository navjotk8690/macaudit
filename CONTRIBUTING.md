# Contributing

Thank you for your interest in MacAudit.

## Development

- Follow existing coding style.
- Keep the project read-only.
- Do not introduce telemetry or cloud dependencies.
- Ensure new detections include evidence and tests where practical.

## Pull Requests

- Keep PRs focused.
- Explain the problem and solution.
- Update documentation when behaviour changes.
- Ensure shell scripts pass `bash -n` and Python files compile.

## Reporting Bugs

Please include:
- macOS version
- MacAudit version
- Steps to reproduce
- Relevant log snippets (redacted if needed)
